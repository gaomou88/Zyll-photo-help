# Zyll Photo Guide

User guide for Zyll Photo, in English, 简体中文, 繁體中文 and 日本語. Published with GitHub Pages at <https://gaomou88.github.io/Zyll-photo-help/>.

- `index.html` sends visitors to their language.
- `en/`, `zh-Hans/`, `zh-Hant/`, `ja/`: one page per language. Section anchors (`#download`, `#connect`, `#undo`, `#faq`) are the same in every language, so the app can link straight to a step.

The helper tool itself lives in [Zyll-photo-helper](https://github.com/gaomou88/Zyll-photo-helper).
