讓 Zyll 相簿連接系統相片挑選器

連接雲端媒體後，其他應用程式（聊天、郵件、社群應用程式等）開啟的系統相片挑選器中，可以直接看到並傳送 Zyll 相簿雲端硬碟中的相片。設定約 3 分鐘，只需做一次。

準備工作

  • Android 15 或更新版本
  • 從 Google Play 安裝的 Zyll 相簿，並已解鎖 Pro
  • 連線 Wi-Fi（無線偵錯只能在 Wi-Fi 下開啟，不會產生網路流量）
  • 約 3 分鐘

為什麼需要獨立的助手工具？

Android 只允許系統白名單中的應用程式作為「雲端媒體應用程式」。將 Zyll 相簿加入名單需要用到系統偵錯權限，而 Google Play 上的應用程式不使用這種權限。因此這一步交給開源小工具「Zyll 相簿助手」完成：執行一次後解除安裝即可，設定會保留。

助手不是必要的：如果你不想安裝它，也可以在電腦上用 ADB 指令自行連接，效果完全相同。

1. 下載並安裝助手

  1. 在手機上開啟最新版本頁面，下載 zyll-photo-helper-vX.Y.Z.apk。
  2. 開啟下載的檔案。如果系統提示，請允許瀏覽器「安裝不明應用程式」，裝完可以再關閉。
  3. 選用：以發布頁上的 .sha256 檔案核對安裝檔的 SHA-256。完整原始碼在 GitHub。

2. 開啟開發人員選項

  1. 前往 設定 → 關於手機（部分手機在「關於手機 → 軟體資訊」中）。
  2. 連續點按 版本號碼 7 次，直到出現「你現在已成為開發人員」。

3. 配對並連接

  1. 開啟 Zyll 相簿助手，點 連接，查看它將執行的指令，勾選同意後繼續。
  2. 點 開始配對，如有提示請允許通知，隨後會開啟開發人員選項。
  3. 開啟 無線偵錯，點進去選擇 使用配對碼配對裝置。
  4. 保持配對對話框開啟，下拉通知欄，在助手的通知中輸入 6 位數配對碼。
  5. 看到 配對成功 後回到助手，點 連接。建議保持勾選「完成後自動關閉無線偵錯」。

4. 在相片挑選器中選擇 Zyll 相簿

  1. 在助手中點 開啟相片挑選器設定（或開啟任一相片挑選器，點 ⋮ → 設定）。
  2. 在 雲端媒體應用程式 中選擇 Zyll 相簿。
  3. 開啟 Zyll 相簿，連接雲端媒體 頁面應顯示 已連線。

5. 解除安裝助手

之後不再需要助手了。點 解除安裝本助手，或像一般應用程式一樣解除安裝即可，設定會保留。

不裝助手：用 ADB 指令自行連接

助手做的事只是執行下面幾條固定指令，你也可以在電腦上自己輸入，效果完全相同。Zyll 相簿本身不會執行其中任何一條。需要一台裝有 Android SDK Platform-Tools（adb）的電腦。

  1. 在手機上開啟「開發人員選項 → USB 偵錯」，用傳輸線連接電腦。手機跳出提示時選擇允許偵錯。（也可以用無線偵錯配對後 adb connect。）
  2. 在電腦的終端機輸入下面這條，進入手機的命令列。之後的指令都在這裡輸入，不要再加 adb shell 前綴：
    adb shell
  3. 先看看名單裡已經有哪些應用程式：
    device_config get mediaprovider allowed_cloud_providers
  4. 如果輸出的是 null 或什麼都沒有，直接加入 Zyll 相簿：
    device_config override mediaprovider allowed_cloud_providers com.zyll.photo
    如果輸出了套件名稱（例如 com.google.android.apps.photos），要把原有的全部保留，用半形逗號接上 Zyll 相簿，中間不要有空格，例如：
    device_config override mediaprovider allowed_cloud_providers com.google.android.apps.photos,com.zyll.photo
  5. 開啟相片挑選器的雲端媒體功能：
    device_config override mediaprovider cloud_media_feature_enabled true
  6. 輸入 exit 離開，然後依照上面第 4 步在相片挑選器裡選擇 Zyll 相簿。完成後可以關閉 USB 偵錯。

解除時在 adb shell 裡執行：

device_config clear_override mediaprovider allowed_cloud_providers
device_config clear_override mediaprovider cloud_media_feature_enabled

為什麼要先進入 adb shell：Windows PowerShell 會把指令裡沒加引號的逗號當成分隔符號，直接在電腦上帶前綴輸入，名單會被拆壞。

如何解除

重新安裝助手，點 解除，以相同方式配對即可。相片挑選器會還原成系統原本的設定。也可以在「開發人員選項 → 無線偵錯 → 已配對的裝置」中刪除舊的配對紀錄。

常見問題

這樣安全嗎？
助手只在本機執行它向你顯示的那幾條固定指令，不連線網際網路，原始碼公開。完成後關閉無線偵錯，連線即中斷。
配對失敗或找不到連接埠
輸入配對碼時配對對話框必須保持開啟，手機必須連著 Wi-Fi。如果通知無法使用，可以分割畫面後在助手中手動輸入連接埠和配對碼。
雲端媒體應用程式列表中沒有 Zyll 相簿
先重新啟動一次手機再看。有些手機廠商移除了相片挑選器的雲端媒體功能，這類手機無法使用。
系統更新後 Zyll 相簿顯示「未偵測到」
大版本系統更新可能會重設這項設定，重新安裝助手再連接一次即可。
