Connect Zyll Photo to the system photo picker

With cloud media connected, the photo picker that other apps open (chat apps, mail, social apps) can show your Zyll Photo cloud library directly. Setup takes about 3 minutes and is done once.

What you need

  • Android 15 or later
  • Zyll Photo from Google Play, with Pro unlocked
  • Wi-Fi (Wireless debugging only works on Wi-Fi; no internet traffic is used)
  • About 3 minutes

Why a separate helper?

Android only lets apps on a system allowlist act as a cloud media app. Adding Zyll Photo to that list needs the system's debugging permission, which apps from Google Play don't use. So this one step is done by a small open-source helper, Zyll Photo Helper. You run it once and then uninstall it. The setting stays.

1. Download and install the helper

  1. Open the latest release on your phone and download zyll-photo-helper-vX.Y.Z.apk.
  2. Open the downloaded file. If Android asks, allow your browser to install unknown apps for this one install. You can turn it off again afterwards.
  3. Optional: compare the file's SHA-256 with the .sha256 file on the release page. The full source code is at GitHub.

2. Turn on Developer options

  1. Go to Settings → About phone (on some phones: About phone → Software information).
  2. Tap Build number 7 times until you see "You are now a developer".

3. Pair and connect

  1. Open Zyll Photo Helper, tap Connect, read the list of commands it will run, tick the box and continue.
  2. Tap Start pairing. Allow notifications if asked. Developer options opens.
  3. Turn on Wireless debugging, open it, and tap Pair device with pairing code.
  4. Keep that dialog open. Pull down the notification shade and type the 6-digit code into the helper's notification.
  5. When you see Paired, go back to the helper and tap Connect. Keep "Turn off wireless debugging when done" ticked.

4. Choose Zyll Photo in the photo picker

  1. Tap Open photo picker settings in the helper (or open any photo picker, tap ⋮ → Settings).
  2. Under Cloud media app, choose Zyll Photo.
  3. Open Zyll Photo. Under Connect cloud media it should now show Connected.

5. Uninstall the helper

You don't need the helper any more. Tap Uninstall this helper or remove it like any other app. The setting stays.

Undo

Install the helper again, tap Undo and pair the same way. The photo picker goes back to exactly what the system had before. You can also remove old pairings in Developer options → Wireless debugging → Paired devices.

Questions

Is this safe?
The helper only runs the fixed commands it shows you, only on this phone, and never connects to the internet. The source code is public. Turning wireless debugging off afterwards closes the connection.
Pairing fails or the port is not found
The pairing dialog must stay open while you type the code, and the phone must be on Wi-Fi. If the notification doesn't work, use split screen and the manual entry in the helper.
Zyll Photo is not in the Cloud media app list
Restart the phone once, then check again. Some phone makers remove the cloud media feature from their photo picker; in that case it can't be used on that phone.
Zyll Photo says "not detected" after a system update
A major system update can reset the setting. Install the helper and connect again.
