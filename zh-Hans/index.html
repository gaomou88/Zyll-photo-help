让 Zyll 相册接入系统照片选择器

接入云端媒体后，其他应用（聊天、邮件、社交应用等）打开的系统照片选择器里，可以直接看到并发送 Zyll 相册网盘里的照片。设置约 3 分钟，只需做一次。

准备工作

  • Android 15 或更高版本
  • 从 Google Play 安装的 Zyll 相册，并已解锁 Pro
  • 连接 Wi-Fi（无线调试只能在 Wi-Fi 下打开，不会产生网络流量）
  • 约 3 分钟

为什么要单独的助手工具？

安卓只允许系统白名单里的应用作为“云端媒体应用”。把 Zyll 相册加进名单需要用到系统调试权限，而 Google Play 上的应用不使用这种权限。所以这一步交给一个开源的小工具“Zyll 相册助手”来做：运行一次，然后卸载即可，设置会保留。助手不是必须的：如果你不想安装它，也可以在电脑上用 ADB 命令自行接入，效果完全一样。

1. 下载并安装助手

  1. 在手机上打开最新版本页面，下载 zyll-photo-helper-vX.Y.Z.apk。
  2. 打开下载的文件。如果系统提示，请允许浏览器“安装未知应用”，装完可以再关掉。
  3. 可选：用发布页上的 .sha256 文件核对安装包的 SHA-256。完整源码在 GitHub。

2. 打开开发者选项

  1. 进入 设置 → 关于手机（部分手机在“关于手机 → 软件信息”里）。
  2. 连续点击 版本号 7 次，直到提示“您已处于开发者模式”。

3. 配对并接入

  1. 打开 Zyll 相册助手，点 接入，看一下它将执行的命令，勾选同意后继续。
  2. 点 开始配对，如有提示请允许通知，随后会打开开发者选项。
  3. 打开 无线调试，点进去选择 使用配对码配对设备。
  4. 保持配对对话框打开，下拉通知栏，在助手的通知里输入 6 位配对码。
  5. 看到 配对成功 后回到助手，点 接入。建议保持勾选“完成后自动关闭无线调试”。

4. 在照片选择器里选择 Zyll 相册

  1. 在助手里点 打开照片选择器设置（或任意打开一个照片选择器，点 ⋮ → 设置）。
  2. 在 云端媒体应用 里选择 Zyll 相册。
  3. 打开 Zyll 相册，接入云端媒体 页面应显示 已连接。

5. 卸载助手

之后不再需要助手了。点 卸载本助手，或像普通应用一样卸载即可，设置会保留。

不装助手：用 ADB 命令自行接入

助手做的事只是执行下面几条固定命令，你也可以在电脑上自己输入，效果完全一样。Zyll 相册本身不会执行其中任何一条。需要一台装有 Android SDK Platform-Tools（adb）的电脑。

  1. 在手机上打开“开发者选项 → USB 调试”，用数据线连接电脑。手机弹出提示时选择允许调试。（也可以用无线调试配对后 adb connect。）
  2. 在电脑的终端里输入下面这条，进入手机的命令行。之后的命令都在这里输入，不要再加 adb shell 前缀：
    adb shell
  3. 先看看名单里已经有哪些应用：
    device_config get mediaprovider allowed_cloud_providers
  4. 如果输出的是 null 或什么都没有，直接加入 Zyll 相册：
    device_config override mediaprovider allowed_cloud_providers com.zyll.photo
    如果输出了包名（比如 com.google.android.apps.photos），要把原有的全部保留，用英文逗号接上 Zyll 相册，中间不要有空格，例如：
    device_config override mediaprovider allowed_cloud_providers com.google.android.apps.photos,com.zyll.photo
  5. 打开照片选择器的云端媒体功能：
    device_config override mediaprovider cloud_media_feature_enabled true
  6. 输入 exit 退出，然后按上面第 4 步在照片选择器里选择 Zyll 相册。完成后可以关闭 USB 调试。

解除时在 adb shell 里执行：

device_config clear_override mediaprovider allowed_cloud_providers
device_config clear_override mediaprovider cloud_media_feature_enabled

为什么要先进入 adb shell：Windows PowerShell 会把命令里没加引号的逗号当成分隔符，直接在电脑上带前缀输入，名单会被拆坏。

如何解除

重新安装助手，点 解除，按同样的方式配对即可。照片选择器会恢复成系统原来的设置。也可以在“开发者选项 → 无线调试 → 已配对的设备”里删除旧的配对记录。

常见问题

这样安全吗？
助手只在本机执行它展示给你的那几条固定命令，不连接互联网，源码公开。完成后关闭无线调试，连接即断开。
配对失败或找不到端口
输入配对码时配对对话框必须保持打开，手机必须连着 Wi-Fi。如果通知不好用，可以分屏后在助手里手动输入端口和配对码。
云端媒体应用列表里没有 Zyll 相册
先重启一次手机再看。有些手机厂商去掉了照片选择器的云端媒体功能，这种手机上无法使用。
系统更新后 Zyll 相册显示“未检测到”
大版本系统更新可能会重置这项设置，重新安装助手再接入一次即可。
